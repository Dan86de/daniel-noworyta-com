# Component Organization

## Directory Structure

- `src/components/catalyst/` - UI component library (buttons, forms, layout primitives)
- `src/components/every-layout-components/` - Layout primitives (Stack, Center, Box, Grid, etc.)
- `src/components/ui/` - Custom UI components (article cards, mobile menu, etc.)
- `src/components/mdx/` - MDX rendering components
